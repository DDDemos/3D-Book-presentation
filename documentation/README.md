# Documentation

[Project README](../README.md)

Use the authoring guides to change the presentation's content. You do not need to modify
the camera, book geometry, or controller to add slides.

- [Adding slides](adding-slides.md): prepare images, register slides, set titles and
  descriptions, reorder content, and check the result.
- [Adding links and text](adding-links-and-text.md): attach a website, a copyable prompt,
  or both to a specific slide, with complete configuration examples.
- [Code reference](code-reference.md): the main classes and factory functions, their
  methods, indexing conventions, and the startup/navigation flow.

The files you will edit most often are [js/presentation.js](../js/presentation.js),
the images in [assets/slides/](../assets/slides/), and text files in
[assets/text/](../assets/text/). Save your edits and reload the served presentation to
apply configuration changes. The optional browser editor only previews temporary images;
it does not save content back to these files.
